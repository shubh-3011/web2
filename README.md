# web2

An inventory web app front end: stock-in and stock-out pages, a live item counter, QR/barcode
scanning, and a data-export utility. Built with vanilla HTML, CSS and JavaScript and bundled with
Vite.

## Features

- Stock-in and stock-out forms
- Live item counter
- QR / barcode scanning (`html5-qrcode`)
- Export and download data bundles (`jszip`)

## Stack

HTML, CSS, JavaScript, Vite, html5-qrcode, JSZip

## Run

```
npm install
npm run dev
```

Then open the local Vite URL printed in the terminal.
